# OVO Hydro Calendar

A subscribed Apple Calendar feed that checks the official OVO Hydro event listing every morning and republishes changes through GitHub Pages.

## Calendar address

`https://ewantomhunter-bot.github.io/ovo-hydro-calendar/ovo-hydro.ics`

## Set-up

1. Upload this project's contents to the `main` branch.
2. Open **Actions** and run **Update OVO Hydro calendar**.
3. Open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**.
5. Select branch **main** and folder **/docs**, then save.
6. Open `https://ewantomhunter-bot.github.io/ovo-hydro-calendar/` after Pages publishes.

On iPhone, add the calendar under **Settings → Apps → Calendar → Calendar Accounts → Add Account → Other → Add Subscribed Calendar**.
